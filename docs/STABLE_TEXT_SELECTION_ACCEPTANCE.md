# 稳定文本锚点与连续选区验收记录

## 实现范围

- `src/reader/text-anchor.js` 提供版本化位置/选区、书籍指纹、UTF-16 偏移、结构路径/EPUB CFI 兼容字段、exact/prefix/suffix 回退、比较、序列化、范围文本提取、DOM 端点和当前页矩形解析。
- EPUB/TXT 使用章节或文档逻辑位置，字号、字体、行距、字距、段距和页边距变化只触发重排，不改变笔记选区锚点；EPUB 章节边界由连续选区控制器载入相邻章节。
- PDF 使用页码、页内规范化文本偏移、TextLayer itemIndex/itemOffset 快速路径和上下文恢复；缩放/旋转后只重建可见页范围。无文本层页面显示不可选择提示。
- 旧笔记保留原有页码用于显示，但没有上下文时不会猜测并挂到新文字；新笔记保存版本化范围锚点。

## 可复现检查

- `npm run test:all`：8 个测试文件全部通过，覆盖序列化/解析/比较、重排回退与失效、EPUB/TXT 跨章节反向范围、PDF 三页正反向范围/无文本层、异步边缘翻页防抖与渲染锁、旧笔记兼容。
- 浏览器 DOM 验收：本地 Vite 页面导入 `tests/fixtures/reader-selection.txt`，拖选后操作栏出现；字号改为 32px 重排后，锚点仍解析并恢复同一原生高亮。
- Android 验收缺口：当前环境没有 `adb` 或 `emulator` 命令，也未发现可用 Android 设备/模拟器，因此未宣称完成 Android 实机手势验收。最终 APK 仍通过构建及新鲜度校验。
